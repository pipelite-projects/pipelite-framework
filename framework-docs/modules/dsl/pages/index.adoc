= DSL
:description: Il Domain Specific Language di Pipelite per la definizione dichiarativa dei flow

Il DSL di Pipelite è un'API Java fluente e type-safe che permette di definire pipeline di integrazione in modo dichiarativo.
Il punto di ingresso è sempre `Pipelite.defineFlow(name)`, che restituisce un builder con step vincolati dalla gerarchia di interfacce.

== Gerarchia delle operazioni

[source]
----
FlowOperations
  └─ .fromSource(url)  ──► SourceOperations
                               extends ProcessOperations
                                 ├─ .process(...)
                                 ├─ .transformPayload(...)
                                 ├─ .filter(...)
                                 ├─ .wireTap(...)
                                 ├─ .toRoute(...)        ──► BuildOperations
                                 └─ .toSink(url)         ──► SinkOperations
                                                               extends BuildOperations
                                                                 ├─ .withRetryChannel()
                                                                 ├─ .withErrorChannel(...)
                                                                 └─ .build()
----

La gerarchia di interfacce garantisce che il compilatore Java imponga la corretta sequenza: source → processori → sink → error handling → build.
