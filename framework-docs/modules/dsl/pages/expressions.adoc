= Expressions
:description: Expression engine syntax for Pipelite filter and conditional routing

The `pipelite-expression` module provides a textual expression evaluation engine used by `filter` and `ExpressionCondition`.

== Variables

[cols="1,3"]
|===
|Variable |Resolves to

|`Payload`
|The input payload of the `Exchange` (equivalent to `exchange.getInputPayload()`)

|`Headers`
|The `Headers` of the `Exchange` — index into it with `Headers['name']`
|===

== Operators

[cols="1,3"]
|===
|Operator |Aliases

|`=`
|`==`, `eq`

|`!=`
|`<>`, `neq`

|`&`
|`&&`, `and`

|`\|`
|`\|\|`, `or`

|`>`
|`gt`

|`>=`
|`gte`

|`<`
|`lt`

|`+++<=+++`
|`lte`

|`+` `-` `*` `/` `%` `^`
|arithmetic (sum, subtraction, multiplication, division, modulus, power)
|===

== Functions

Functions are called as `NAME(arg1, arg2, ...)`:

[cols="1,3"]
|===
|Function |Description

|`NOT(x)`
|Boolean negation

|`IF(condition, whenTrue, whenFalse)`
|Conditional value

|`SQRT(x)`
|Square root

|`ROUND(x)`
|Rounding

|`beanProperty(bean, 'path')` (aliases: `bp`, `property`, `prop`, `jsonPath`)
|Reads a (possibly nested, dot-separated) property from an object, e.g. `beanProperty(Payload, 'address.city')`
|===

== Expression examples

[source]
----
// Filter on a header
Headers['status'] eq 'READY'

// Numeric comparison
Headers['priority'] > 5

// Nested bean property
beanProperty(Payload, 'order.total') > 100

// Combined condition
Headers['type'] == 'ORDER' and beanProperty(Payload, 'amount') <= 500
----

== Usage in DSL

=== In filter

[source,java]
----
.filter("only-ready", "Headers['status'] eq 'READY'")
----

The expression is evaluated on each `Exchange`. If the evaluation returns `false`, message processing stops.

=== In ExpressionCondition

[source,java]
----
.toRoute(route -> route.contentBased()
    .when(new ExpressionCondition("Headers['type'] == 'PAYMENT'"), "payment-flow")
    .otherwise("default-flow")
    .build()
)
----

NOTE: The expression engine is intentionally simple. For complex conditional logic, prefer using a `Processor` with standard Java code.
