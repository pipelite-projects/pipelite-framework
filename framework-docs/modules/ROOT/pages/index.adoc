= Pipelite Framework
:description: Documentazione di riferimento del Pipelite Framework

Pipelite è un framework Java leggero per la creazione di applicazioni di integrazione enterprise (EAI) basate su messaggi.
Implementa i principali *Enterprise Integration Patterns* (EIP) offrendo un DSL fluente, un motore di esecuzione asincrono e un sistema di channel adapter estensibile.
