= Channel Adapters
:description: Overview of all channel adapters available in Pipelite

*Channel Adapters* are the connectors that link a Pipelite pipeline to external systems.
Each adapter implements the SPI interface `ChannelAdapter` and is automatically discovered at runtime via classpath scan.

== Available adapters

[cols="1,1,1,3"]
|===
|Adapter |URL scheme |Module |Description

|xref:http.adoc[HTTP]
|`http://`
|`http-channel-adapter`
|Inbound HTTP server (Undertow) and outbound HTTP client.

|xref:kafka.adoc[Kafka]
|`kafka://`
|`kafka-channel-adapter`
|Apache Kafka consumer and producer.

|xref:file.adoc[File]
|`file://`
|`file-channel-adapter`
|Filesystem tail-polling source and file-writing sink.

|xref:time.adoc[Time]
|`time://`
|`default-channel-adapters`
|Periodic tick generator (cron-like).

|xref:slf4j.adoc[SLF4J]
|`slf4j://`
|`default-channel-adapters`
|Payload logging via SLF4J (sink only).

|xref:queue.adoc[Queue]
|`queue://`
|`default-channel-adapters`
|The queue in front of an internal flow, to chain flows.
|===

== Automatic discovery

Adapters are registered via the file:

[source]
----
META-INF/pipelite.factories
----

Each line maps a protocol to the fully qualified name of a class implementing `ChannelAdapter`:

[source,properties]
----
queue=io.pipelite.components.queue.QueueChannelAdapter
time=io.pipelite.components.time.TimeChannelAdapter
----

Every such file on the classpath is scanned at context startup.
