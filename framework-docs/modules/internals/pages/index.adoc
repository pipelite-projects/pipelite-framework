= Internals (Contributor Reference)
:description: Implementation details of Pipelite Framework internals, intended for contributors

WARNING: This module documents internal implementation details of Pipelite Framework, intended for contributors to the framework itself. It is *not* required reading to define, run, or extend flows as a user of the framework. See xref:core:index.adoc[Core] or xref:extensibility:index.adoc[Extensibility] instead.
