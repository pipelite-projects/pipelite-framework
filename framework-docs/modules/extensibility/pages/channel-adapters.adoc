= Custom Channel Adapters
:description: Guide to implementing a custom ChannelAdapter via the Pipelite SPI

Pipelite exposes an open SPI that allows custom adapters to be created for any external system, following the same contract used by the built-in HTTP, Kafka, File, Time, SLF4J, and Link adapters.

== Implementing ChannelAdapter

[source,java]
----
public class MyCustomChannelAdapter implements ChannelAdapter {

    @Override
    public Endpoint createEndpoint(String url) {
        EndpointURL endpointURL = EndpointURL.parse(url);
        return new MyCustomEndpoint(endpointURL, this);
    }
}
----

== Implementing Endpoint

[source,java]
----
public class MyCustomEndpoint extends DefaultEndpoint {

    public MyCustomEndpoint(EndpointURL url, ChannelAdapter adapter) {
        super(url, adapter);
    }

    @Override
    public Consumer createConsumer() {
        return new MyCustomConsumer(this);    // for use as source
    }

    @Override
    public Producer createProducer() {
        return new MyCustomProducer(this);    // for use as sink
    }
}
----

== Implementing Consumer (source)

For *event-driven* consumers:

[source,java]
----
public class MyCustomConsumer extends AbstractConsumer
    implements EventDrivenConsumer {

    public void onMessage(Object data) {
        Exchange exchange = exchangeFactory.createExchange(data);
        process(exchange);
    }
}
----

For *polling* consumers:

[source,java]
----
public class MyCustomPollingConsumer extends DefaultPollingConsumer {

    @Override
    protected Exchange poll() {
        Object data = mySystem.fetchNext();
        if (data == null) return null;
        return exchangeFactory.createExchange(data);
    }
}
----

== Implementing Producer (sink)

[source,java]
----
public class MyCustomProducer extends AbstractProducer {

    @Override
    public void produce(Exchange exchange) throws Exception {
        Object payload = exchange.getInputPayload();
        mySystem.send(payload);
    }
}
----

== Registration via classpath scan

Create the registration file in the `resources` directory of your module:

[source]
----
src/main/resources/META-INF/pipelite/adapters
----

File content (one class per line):

[source]
----
com.example.adapters.MyCustomChannelAdapter
----

The framework automatically loads all classes registered in this file at `PipeliteContext` startup.

== Integration with the context lifecycle

If your adapter needs to be notified of context startup and shutdown, implement `ContextEventListener`:

[source,java]
----
public class MyCustomChannelAdapter
    implements ChannelAdapter, ContextEventListener {

    @Override
    public void onContextStarted() {
        // start connection to the external system
    }

    @Override
    public void onContextStopped() {
        // graceful connection shutdown
    }
}
----

== Honoring pre/post-processors and exception handling

`Consumer` and `Producer` both extend `FlowNode`, which carries `addExchangePreProcessor(...)`, `addExchangePostProcessor(...)`, and `setExceptionHandler(...)`. Extending `AbstractConsumer`/`AbstractProducer` (as shown above) gives your adapter these behaviors for free — every `Exchange` your adapter hands to the framework is automatically run through any pre/post-processors and exception handler registered on the flow.

If instead you implement `Consumer`, `Producer`, or `FlowNode` directly rather than extending the `Abstract*` base classes, you are responsible for invoking these yourself. See xref:exchange-processors.adoc[Exchange Pre/Post Processors] and xref:exception-handling-spi.adoc[Exception Handling SPI] for the contracts involved.

== Configuring your adapter

If your adapter needs application-supplied configuration (connection settings, credentials), see xref:channel-configuration.adoc[Channel Configuration SPI].

If it needs to persist durable state on the local filesystem (as the built-in `file-channel-adapter` does), see xref:shared-filesystem-storage.adoc[Shared Filesystem Storage] instead of deriving your own directory-resolution and file-locking logic.
