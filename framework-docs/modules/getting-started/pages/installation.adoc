= Installazione
:description: Come aggiungere Pipelite Framework come dipendenza Maven

== Dipendenza core (standalone)

Per usare Pipelite senza Spring Boot aggiungi il modulo core al tuo `pom.xml`:

[source,xml,subs="attributes+"]
----
<dependency>
    <groupId>{project-group-id}</groupId>
    <artifactId>pipelite-core</artifactId>
    <version>{project-version}</version>
</dependency>
----

Il modulo `pipelite-core` include transitivamente `pipelite-common`, `pipelite-spi`, `pipelite-dsl`, `pipelite-expression` e il modulo `default-channel-adapters`.

== Integrazione Spring Boot

Per applicazioni Spring Boot usa invece lo starter dedicato:

[source,xml,subs="attributes+"]
----
<dependency>
    <groupId>{project-group-id}</groupId>
    <artifactId>pipelite-spring-starter</artifactId>
    <version>{project-version}</version>
</dependency>
----

Lo starter aggiunge l'autoconfiguration e la gestione automatica del ciclo di vita del `PipeliteContext`.

== Channel Adapter opzionali

Gli adapter HTTP e Kafka devono essere aggiunti esplicitamente:

[source,xml,subs="attributes+"]
----
<!-- HTTP (Undertow) -->
<dependency>
    <groupId>{project-group-id}</groupId>
    <artifactId>http-channel-adapter</artifactId>
    <version>{project-version}</version>
</dependency>

<!-- Apache Kafka -->
<dependency>
    <groupId>{project-group-id}</groupId>
    <artifactId>kafka-channel-adapter</artifactId>
    <version>{project-version}</version>
</dependency>
----

Gli adapter `time`, `slf4j` e `link` sono inclusi in `default-channel-adapters`, già presente come dipendenza transitiva di `pipelite-core`.

== Distribuzione

Pipelite è pubblicato su Maven Central.
Non è necessaria nessuna configurazione aggiuntiva di repository.
