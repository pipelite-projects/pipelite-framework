= Pipelite Framework
:description: Pipelite Framework Reference Documentation

Pipelite is a lightweight Java framework for building enterprise application integration (EAI) systems based on message passing.
It implements the core *Enterprise Integration Patterns* (EIP), providing a fluent DSL, an asynchronous execution engine, and an extensible channel adapter system.
