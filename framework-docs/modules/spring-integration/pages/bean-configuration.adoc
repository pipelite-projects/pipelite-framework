= Configuring Channel Adapters via Beans
:description: Configuring channel adapters in a Spring Boot application via PipeliteContextInitializer beans

Channel adapter configuration in a Spring Boot application is done through a bean implementing `PipeliteContextInitializer`, which the framework calls with the `PipeliteContext` before it starts. Inside it, register a `ChannelConfigurer` (see xref:extensibility:channel-configuration.adoc[Channel Configuration SPI]) via `ConfigurablePipeliteContext#addChannelConfigurer(...)`.

[source,java]
----
@Component
public class MyChannelConfiguration implements PipeliteContextInitializer {

    @Override
    public void initializeContext(PipeliteContext context) {
        ConfigurablePipeliteContext configurableContext = (ConfigurablePipeliteContext) context;

        configurableContext.addChannelConfigurer((KafkaChannelConfigurer) config -> {
            config.setBootstrapServers("kafka-broker:9092");
            config.setGroupId("my-app-group");
            config.setAutoOffsetReset("earliest");
        });

        configurableContext.addChannelConfigurer((FileChannelConfigurer) config ->
            config.setStateDirectory(Path.of("/var/lib/myapp/pipelite-file-state")));
    }
}
----

A single `PipeliteContextInitializer` bean can register configurers for as many adapters as needed. See xref:channel-adapters:kafka.adoc[Kafka] and xref:channel-adapters:file.adoc[File] for the full set of configurable properties per adapter.
