= Spring Boot Integration
:description: Integrating Pipelite with Spring Boot via the pipelite-spring-starter module

The `pipelite-spring-starter` module provides native integration with Spring Boot {spring-boot-version}+.

== Features

* Automatic autoconfiguration of the `PipeliteContext`.
* Automatic registration of `FlowDefinition` beans exposed as `@Bean`.
* Lifecycle management via Spring's `SmartLifecycle`.
* `@EnablePipelite` annotation to activate the integration.
