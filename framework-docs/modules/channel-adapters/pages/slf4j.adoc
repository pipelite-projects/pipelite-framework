= SLF4J Channel Adapter
:description: Adapter per il logging del payload tramite SLF4J

L'adapter `slf4j` è un sink che logga il payload del messaggio tramite l'API SLF4J.
È utile per il debugging, l'audit e il logging di output intermedi.

== Disponibilità

Incluso in `default-channel-adapters`, transitivamente disponibile con `pipelite-core`.

== Utilizzo come sink

[source,java]
----
.toSink("slf4j://my-logger")
----

Il `Slf4jProducer` logga il payload dell'`Exchange` di output a livello `INFO` usando il logger con il nome specificato nell'URL.

=== Formato URL

[source]
----
slf4j://<logger-name>
----

[cols="1,3"]
|===
|Parametro |Descrizione

|`logger-name`
|Nome del logger SLF4J (es. `my-logger` → `LoggerFactory.getLogger("my-logger")`)
|===

== Utilizzo nel WireTap

L'adapter SLF4J è particolarmente utile come destinazione di un WireTap per il logging di audit:

[source,java]
----
.wireTap("audit-tap", "slf4j://audit-logger")
.toSink("kafka://output-topic")
----

In questo caso l'Exchange viene loggato da SLF4J e contemporaneamente inviato a Kafka.

NOTE: L'adapter `slf4j` è esclusivamente un *sink*: non supporta l'uso come sorgente di un flow.
