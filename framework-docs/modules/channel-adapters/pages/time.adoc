= Time Channel Adapter
:description: Adapter per la generazione di tick periodici come sorgente di flow

L'adapter `time` genera tick periodici e li immette come messaggi nel flow.
È utile per pipeline schedulate, polling di risorse esterne e workflow basati su timer.

== Disponibilità

Incluso in `default-channel-adapters`, transitivamente disponibile con `pipelite-core`.

== Utilizzo

[source,java]
----
Pipelite.defineFlow("scheduled-flow")
    .fromSource("time://ticker?period=5000")   // <1>
    .process("check", exchange -> {
        // logica eseguita ogni 5 secondi
    })
    .toSink("slf4j://log")
    .build();
----
<1> Genera un tick ogni 5000 ms.

== Formato URL

[source]
----
time://<name>[?period=<ms>]
----

[cols="1,1,3"]
|===
|Parametro |Default |Descrizione

|`name`
|(required)
|Nome logico del timer (es. `ticker`, `heartbeat`)

|`period`
|`1000`
|Periodo di tick in millisecondi
|===

== Meccanismo interno

Il `TimePollingConsumer` usa un `ScheduledExecutorService` tramite `TimeService`.
Ad ogni tick viene creato un nuovo `Exchange` con payload contenente il timestamp corrente.
Il consumer viene avviato e fermato insieme al `PipeliteContext`.
